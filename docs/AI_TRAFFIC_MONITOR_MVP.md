# AI Traffic Monitor MVP: роль Hermes

Дата фиксации: 2026-06-19

Hermes в проекте «Точка притяжения» отвечает за смысловой ответ пользователю. Учет AI-трафика, расходы, тарифные правила и будущая монетизация находятся на стороне `CabinetAstroGeo`.

## Роль Hermes

- Формировать ответ пользователю.
- Использовать подготовленный контекст.
- Не быть владельцем учета AI-расходов.
- Не управлять тарифами и лимитами.
- Не хранить историю финансовых операций.

## Роль связанных слоев

- `CabinetAstroGeo` — главный владелец учета и отчетности.
- `tp-hermes-bridge` — отправляет usage events после AI-вызова.
- Hermes — смысловой слой.

## MVP-решение

В MVP используется одна основная недорогая модель DeepSeek. Мультимодельность и выбор модели пользователем не реализуются. Но в каждом usage event фиксируются `provider` и `model`, чтобы сохранить задел на будущее.

## Пользовательский принцип

Пользователю не показываются токены как главная ценность. В будущем пользователь должен видеть понятный AI-ресурс: включенный ресурс по тарифу, пакеты глубоких разборов и расширенный ресурс Гермеса.
