# Изолированное извлечение из текста

`tp_execution_mode: sourced_text_v1` — opt-in для Wikipedia в «Белом листе».
Обычные запросы без этого поля не меняются.

- Ровно system + user, только текст, суммарно до 28 000 символов.
- Без streaming, инструментов, общей сессии, памяти и context files.
- Одна итерация; предел ответа 2 200 токенов.
- Используются штатные durable request identity и учёт провайдера.
- Ответ отмечен `X-Hermes-Context-Isolation: strict-v1`.
- Извлечение не является независимой проверкой истинности источника.

Причина: обычный агент пытался запускать terminal/execute_code для уже
переданной статьи и зависал на approval. Извлечение не требует этих действий.

Проверка: Docker build и 87 unittest внутри образа, без сети и секретов.
Развёртывать сначала Hermes test, затем потребителя Cabinet test.
