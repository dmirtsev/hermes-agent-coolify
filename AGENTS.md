# Экономная работа со сборкой

Общий рабочий регламент находится в
[tp-architecture](https://github.com/dmirtsev/tp-architecture/blob/codex/local-stand-20261019/docs/BUILD_AND_CANDIDATE_POLICY.md).
Это рабочая, ещё не принятая версия; она не запускает CI, модель, Coolify или
deploy.

Перед изменением wrapper и контрактов выполняй безопасные локальные проверки
из `docs/BUILD_ECONOMY.md`. Не запускай LLM, не делай платных provider-запросов
и не меняй runtime, ключи, тома или серверные профили без отдельного задания.

У проекта три самостоятельных профиля `economy`, `balanced`, `strong`.
Legacy Hermes — отдельный runtime совместимости и не является базой для merge.
Кандидат может быть использован повторно только при совпадении SHA, платформы,
закреплённого upstream-образа, параметров сборки и обязательных проверок.
